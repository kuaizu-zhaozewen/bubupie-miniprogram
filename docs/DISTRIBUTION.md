# 分销策略｜关键词领券与原价20%佣金

版本：V3.6 / 2026-11-23。代理机构、商家及个人代理同步推广，使用各自专属推广关键词和商城承接页。下列领券、归因、退款及结算规则已由用户本轮确认；5元、10元是券值配置示例。

## 消费者路径

在商城顶部输入有效推广关键词 → 点击搜索 → 登录后领取当日无门槛券 → 选购任意商品 → 展示原价、用券抵扣和实付 → 确认订单与付款 → 收货及售后。

推广券全商城商品通用，无最低消费门槛。每人每天限领一张，同日搜索其他代理关键词不重复领取，也不替换为更高面额；优惠券按北京时间领取日结束时失效，不是领取后24小时。实付不低于0，券不兑换现金、不找零。演示每单使用一张推广券；与其他优惠叠加方式尚待运营配置。

## 代理路径

经审核开通代理身份 → 获得专属推广关键词与商城承接页 → 自行推广 → 工作台查看归属订单、原价销售额、退款原价、有效销售额、待结算、可结算、累计已结算和退款待抵扣 → 对账结算。

机构代理和个人代理采用相同的直接销售佣金规则。消费者最近一次成功搜索并校验通过的推广关键词对应代理为新订单归属代理，订单创建时锁定；后续搜索不修改历史订单。领券来源与代理归属分别保存：搜索A关键词领取5元券后再搜索B关键词，不再领券，新订单归B。旧订单不变。商城官方关键词不覆盖最近有效推广关键词对应代理归属；从未搜索有效代理关键词的官方商城订单不产生代理佣金。

## 结算口径

商品原价合计 = 下单时各商品原价快照 × 对应数量之和；运费独立列示，不进入商品佣金基数。

消费者实付 = 商品原价合计 − 本单实际优惠券抵扣。优惠券由平台独立承担，佣金基数不扣除优惠券。

代理佣金 = 归属商品原价合计 × 20%。售出后计提为待结算，确认收货且售后期结束后进入可结算；结算完成才计入已结算。退款商品冲回对应原价销售额和20%佣金，已结算的退款进入后续抵扣/追回应收账，不把退款算成新增收入。

| 场景 | 商品原价 | 券抵扣 | 消费者实付 | 代理佣金 |
| --- | ---: | ---: | ---: | ---: |
| 未用券 | 100元 | 0元 | 100元 | 20元 |
| 5元券 | 100元 | 5元 | 95元 | 20元 |
| 10元券 | 100元 | 10元 | 90元 | 20元 |
| 全额退款 | 冲回100元 | 独立处理券 | 退实际支付额 | 冲回20元 |

平台核算应同时看到商品原价、优惠券实际抵扣、实际收款、佣金及退款。例：原价100元、用券10元、佣金20元，扣除券与佣金后为70元，再承担商品成本、物流和服务成本。券值应结合商品成本与活动预算配置，不将原价销售额误作实际现金收入。

## 后台与运营配置

代理只看到自己的订单及汇总，不读取消费者聊天、生日或其他代理资料。平台后台维护代理审核/停用、推广关键词状态、券面额、发券预算、售后时长、对账单与结算周期。停用关键词不得继续发券或新增归因；已锁定订单仍按记录对账。

券面额正式值、商品售价与上架清单、售后期天数、结算频次、其他优惠叠加、异常订单审核及结算后退款抵扣执行方式尚待运营确定。当前Demo的129/39/19元仅为演示价格，不作为正式报价。

## 本轮交付范围

现有小程序工程已增加商品列表、数量选择、顶部搜索关键词领券、商城与两位代理的演示关键词、模拟订单、收货、售后期结束、整单退款和代理工作台。仅本机缓存，不含服务器、真实微信付款、真实发券和转账。当前消费者入口只使用搜索关键词，不再显示扫描或生成二维码；历史二维码资产仅为旧版兼容。商城和个人中心均可查看“我的优惠券”，按可使用、已使用和已过期分类。
