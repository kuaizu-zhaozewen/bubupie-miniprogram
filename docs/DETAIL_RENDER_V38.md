# IP详情建议与衣装精修 V3.8｜现行交付

2026-11-23。本轮按反馈微调，替代 V3.7 中把穿搭建议放在伙伴首页的方案。

## 页面归属

一级伙伴首页只保留品牌、我的伙伴与 IP 卡片，不显示穿搭、季节或节日建议，也不放添加卡。

点湾月进入二级 IP 详情（pages/fortune/index），在形象与问好下方展示“给湾月的小建议”。点击建议进入三级推荐商城（pages/shop-entry/index），预选分类并优先展示对应商品；再点商品进入四级商品详情。按顶部返回逐层回到推荐商城、IP详情、伙伴首页。二级及更深页面均不显示底栏。

四个一级栏目仍为伙伴、商城、购物袋、我的，共用 app.json 中的同一套原生 tabBar。一级商城主动浏览仍保留底栏，且与从详情进入的推荐商城分别保存分类、搜索状态。

## 图标状态

四个导航图标统一为黑色实心选中、灰色描边未选中，短文字保持。伙伴仍用垂耳小玩偶头像，避免设备语义。PNG 与可编辑 SVG 均在 assets/navigation，脚本 scripts/build-navigation-icons.js 可重建。

## 衣装素材与上身展示

商城和衣橱的10件衣装/配件缩略图，以及海丝套装商品图，换成独立精修透明 PNG。补足布料织纹、刺绣、缝线、纽扣、厚度和柔和阴影。素材位于 assets/shop-v38，不缩小压缩这些新图。

完整海丝套装使用原有实物风格精修图；完整海湾工装、骑楼漫游使用新精修上身图，裸本体也有独立精修图。utils/avatar-presentation.js 按实际四槽组合匹配，components/dress-avatar 同时用于首页、详情和衣橱，保存搭配后同步显示。

任意单件混搭继续使用坐标一致的可编辑分层插画，新增渐变材质、织纹和接触阴影；不把整套图片当作错误的混搭效果。分层图与 SVG 源位于 assets/wardrobe-v38/layers，scripts/build-layer-refinements.js 可重建。它仍是插画式试穿，不是写实实时三维换装；整套精修图与混搭插画的风格存在差异。

新生成素材采用内置 imagegen；逐项最终提示词、输入参考及路径见 [ASSETS_V38.json](ASSETS_V38.json)，说明见 [ASSETS_V38.md](ASSETS_V38.md)。保留原版素材和生成迭代，不覆盖原始实物图。
