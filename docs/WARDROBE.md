# 布布小伴 · 运势优先与三级换装 V3.4

适用：前端、后端、设计与测试人员。2026-11-20。配套原生小程序工程，不含服务器，未发布生产小程序。

## 三分钟体验

1. 微信开发者工具导入工程，保留原AppID。首页点湾月IP卡片先进入二级运势页，再点击湾月形象进入三级衣橱。运势页没有换装控件，衣橱不再作为查看运势的前置入口。
2. 在三级衣橱点“绑定新衣装”，同页展开扫码或手输；填写 `BUBU-DEMO-SILK-001` 并确认解锁首套四件部件。取消、重复绑定及跨账号拒绝逻辑保留。
3. 点“海丝簪花漫游”一键穿戴，或按上衣、下装、鞋履、头饰逐件选择和取下。
4. 绑定 `BUBU-DEMO-WORK-001`、`BUBU-DEMO-ARCADE-001`，试工装上衣 + 沙色短裤 + 海浪青鞋；`BUBU-DEMO-HAT-001` 可试未来帽子接口。
5. 点微信原生返回，从衣橱回到原运势页，再返回首页。运势内容保留，IP形象同步已保存的搭配；退出重进也恢复。账号B复扫A用过的码仍拒绝。
6. 页面底部展开“演示工具”可切换模拟账号、重置和查看14张演示二维码。单件码 `BUBU-DEMO-PIECE-01` 至 `-10` 可逐件绑定，完整对应见 [wardrobe-demo-codes.json](wardrobe-demo-codes.json)。

双击本目录 `换装交互预览.html` 可探索相同 WXML/WXSS 和 Page 方法。它不是微信运行环境，网页扫码用文本输入代替。

## 造型与实物边界

- 实物首发只有水墨雾灰本体 + 海丝簪花漫游；海湾工装、骑楼漫游是首套通过后的规划，Demo 上线不代表实物上市。
- 10件：3上衣、3下装、2双鞋、整圈簪花、探索帽。四槽 `top/bottom/shoes/head` 每槽0或1件。
- base和部件按同一画布对齐，叠放独立PNG，支持真正分件混搭。共用本体固定脸、内收毛绒手、连体波浪瓣脚和水墨雾灰毛色。分层插画是搭配示意，不是实物3D模型或生产几何。
- NFC仅在本体内，衣服、帽子、簪花和鞋无 NFC。磁体全部内埋。更换实物不会自动识别数字穿戴。
- 三级衣橱操作换装，首页和二级运势同步造型；公开今日卡和Canvas分享仍用固定首发图。未绑定衣装时预览首发造型，绑定后取下全部部件显示裸本体。古厝线稿随泉州短衫显示或收起，不遮挡形象入口和换装点击。

## 三类入口

| 类型 | 职责 |
|---|---|
| 本体NFC/公开码 | 访问公开角色卡，不含私码 |
| 本体领养私码 | 账号领取本体实例权益 |
| 衣装私码 | 账号领取对应单件或套组衣装权益，不授予本体 |

每个售出衣装实例必须独立私码，固定关联商品内容；同款各实例不能共用一码。公开演示码不能印在量产商品上。

## 代码与本机状态

`utils/wardrobe.js`保留原目录、核销、权益与穿戴逻辑；`utils/wardrobe-view.js`提供衣橱绑定和换装方法；`pages/fortune/`为二级主体验，形象绑定dress事件进入`pages/character/`三级衣橱。衣橱包含`pages/wardrobe/controls.wxml`，旧wardrobe/index只重定向兼容。首页、运势和衣橱共用dress-avatar分层组件。全局和业务页面配置navigationStyle=default，移除自绘nav-bar注册与标签，原生返回使用微信页面栈。

`bubupie_wardrobe_v1`保存一个状态对象：版本、当前演示账号、code→账号核销表、每个账号的owned列表与四槽look。模拟核销与权益同份写入，同账号幂等、跨账号拒绝；不代表分布式事务或防篡改。确认弹窗取消不领取；确认期间账号变化要求重试。重置只清衣橱，不清本体领养、收藏、昵称或生日。

`mode !== 'mock'` 或 `enableDemoTools !== true` 时关闭演示核销/穿戴并隐藏本机权益，尚无生产服务兜底。原 `mio_` 和 `tami_adoptions` 缓存只为兼容。对用户展示的新本体码是 `BUBU-DEMO-BODY-001`，旧 `TAMI-DEMO` 只兼容旧测试。

## 生产接口建议（尚未实现）

| 操作 | 客户端传入 | 服务端约束 |
|---|---|---|
| 预检 | 私码 | 登录会话，读取商品名称/部件/状态，不发权益 |
| 确认 | 私码、幂等键 | 事务校验、唯一核销与权益发放同时提交 |
| 获取衣橱 | 角色/本体实例ID | 只返回会话账号权益与合法穿戴 |
| 保存搭配 | 四槽look、版本 | 逐件校验归属、slot、角色兼容和撤销状态，整体保存或拒绝 |

同账号复扫返回原权益；已被他人兑换、停用、无效的码不发放。生产码需高熵、不可枚举，避免日志泄露明文。二维码内容和客户端owner都不能作为权限凭据。退款、转赠、跨本体共享、注销及撤销后的穿戴规则待产品/技术确定，Demo未实现。
